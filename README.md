# JAVA-DSA 🧠

This repo is basically my DSA practice playground. I keep adding questions + patterns + solutions as I learn—so expect the structure to grow daily.

## What’s inside?
- Problem solutions (in Java)
- Pattern-wise learning: I try to group stuff by approach (two pointers, sliding window, DP ideas, sorting, etc.) so it’s easier to revise

## How to use it
### 1) Clone
```bash
git clone <your-repo-url>
cd JAVA-DSA
```

### 2) Run Java files
Most folders contain standalone `*.java` files. From the folder where the file is:
```bash
javac FileName.java
java FileName
```

## Notes (casual but important😄)
- Some files are meant to be standalone demos (they include a `main`).
- The goal here is practice + understanding, not perfect production-style project structure.
- If you see an approach label/pattern in a folder, that’s my attempt to learn things in batches.

Keep grinding—happy coding! 🚀
